# Precision Commerce asset provenance

The local Phase 3 handover is the source of the approved Register geometry and AI image generation product illustrations. The application versions are tracked here. Original artwork masters, archived concepts and prototype sources stay in the local handover.

| Application files                                                                                      | Source and placement                                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `public/brand/register-*.svg`                                                                          | Original Register artwork from Phase 3. Horizontal and stacked lockups, symbols and outlined wordmarks in approved colour variants.                                                                     |
| `public/brand/app-*.png`, `public/brand/app-icon.svg`, `src/app/{icon.svg,favicon.ico,apple-icon.png}` | Register application and browser icons. The ICO contains 16, 24, 32 and 48 px frames.                                                                                                                   |
| `public/storefront/hero-*.webp`                                                                        | Dedicated AI image generation illustration of a race bib, stickers, self-inking stamp, acrylic sign and brass plate on graphite. Homepage hero only.                                                               |
| `public/storefront/{stickers,race,mtb,stamp,trophy,laser}-*.webp`                                      | Six individually generated product illustrations. The homepage and known division routes choose these by division slug. Unknown divisions retain working catalogue navigation with a generic pictogram. |
| `src/app/web-fonts/`                                                                                   | Local Instrument Sans, Special Gothic Expanded One and IBM Plex Mono web fonts with their upstream SIL OFL notices. Print-output fonts remain in `public/fonts/`.                                       |

WebPs come from 1536 × 1024 PNG masters and ship as 480 × 320, 960 × 640 and 1440 × 960 derivatives. The app uses browser source selection and reserved aspect ratios. The dedicated hero is prioritised and catalogue tiles are lazy-loaded. Product photos are labelled illustrations. The gallery still uses the existing print-engine image routes and sample labels. No customer or production photography was added.

Register was selected in Phase 3 after a preliminary visual comparison. Trademark clearance and physical reproduction testing remain pending. Physical touch verification and the mobile transformer resize test skip remain open. Real production gallery examples and a fresh live deployment and evaluator-account check remain open for submission.
